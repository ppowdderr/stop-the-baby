## Environment and sync
- Preserve an already-running Studio instance. On machines provisioned with Vinegar, launch using `XDG_SESSION_TYPE=x11 flatpak run org.vinegarhq.Vinegar studio /absolute/path/to/place.rbxl` only if needed.
- Check the running Rojo process and port rather than assume default 34872. Connect the Rojo plugin to that port.
- Source updates sync into the edit place; restart Play/Clients and Servers to copy them into the running test.
- Project property updates may fail in Rojo. Check the plugin's failed-change indicator and inspect the actual property before declaring a setting applied. TextChatService.ChatVersion is one such property: when authorized, select TextChatService in Studio, set ChatVersion to TextChatService in Properties and save the place. This avoids legacy ChatScript SetCoreGuiChatConnections startup errors in local clients.
- The modern Studio UI uses Test menu > Clients and Servers > Server & Clients. Set 2 players in the top toolbar; F7 launches the session. Test > End Session stops server and all clients.
- Each server/client is a separate desktop window. `wmctrl -l` lists window ids; activate by id, then allow activation to settle before maximizing with `wmctrl -r :ACTIVE: -b add,maximized_vert,maximized_horz`.

## Wine input and panels
- The single-client UI is embedded in Studio. Tab hides Roblox's player-list overlay when it obstructs top-right game buttons.
- Window > Output opens logs in each client/server. Capture them separately.
- If pasted command-bar text loses characters, use `xdotool type --delay 20` for nonsecret read-only diagnostics, then click Run. Command bar may be multiline, so Enter alone may not execute.
- To orbit the game camera, hold right mouse down, allow a short event delay, move the mouse, and release. WASD uses camera-relative movement.
- Results last only 10 seconds. For two-client screenshots, prepare both window ids in advance and switch immediately once the first toy appears.
- Studio without published-place DataStore access uses fresh fallback profiles; expected warnings mention DataStore unavailable and Studio fallback profile. Report other errors verbatim, even if they originate in Roblox CoreScripts.

## Procedural art and timing-sensitive observations
- This house is generated by MapBuilder on server startup, not stored as edit-mode geometry. Use Studio Run (F8) for a player-free camera tour, stop, then F5 for real player collision/chore checks. Do not save runtime-generated geometry into the edit place.
- Test > Toggle Client View switches between live player view and server free-camera view. Server view is useful for framing props, but client-only face animation must be verified in client view.
- For precise camera work, a temporary command-bar camera CFrame is an observer-only adjustment; it must not move characters, props or alter AI. Right-mouse navigation may restore Studio's previous camera controller state, so avoid steering after setting a fixed observation camera.
- If Studio overwrites an observer CFrame, set CameraType=Scriptable and Focus as well. Changing FieldOfView may also restore an old pose; apply the desired CFrame again after the FOV change settles. Keep these changes in the disposable Play session.
- Long `xdotool type --delay 20` calls can background before typing completes. Wait for the process to exit before clicking Run; otherwise the partial command can produce a tester-only CommandBar syntax error.
- Wine mouse input is more reliable with a short settling delay before right mouse down, another delay before the relative move, then release. For nonsecret command text, use `xdotool type --delay 20` rather than clipboard paste, which can drop characters. Click the viewport to restore WASD focus after command-bar use.
- First-person camera may lock the pointer and prevent clicking lobby buttons. Scroll out to third person before clicking READY; report this as a usability limitation if still present.
- Random AI events can be missed while steering. Use a wide, fixed view of the passage plus temporary read-only position/Knocked-attribute listeners. Distinguish visible animation from state-only evidence. Remove observers by stopping Play; never force an AI behavior or teleport a prop merely to claim a natural event.
- Knocked props reset at the next READY/start, not immediately on results/lobby return. Check the same prop before/after: Knocked true→false, Anchored false→true, CFrame unequal→equal to HomeCFrame, plus actual fallen/upright geometry.
- Studio Output can be filtered by severity using the All Messages dropdown. Restore All Messages after inspection. If a command-entry error is truncated in the UI, exact CreatorError text is available under Vinegar's `data/vinegar/appdata/Roblox/logs`; avoid sharing whole logs because they include unrelated platform/account metadata.

## Devin Secrets Needed
- Existing authenticated Studio sessions need no secrets.
- If login is required, use `ROBLOX_TEST_ACCOUNT_USERNAME` and `ROBLOX_TEST_ACCOUNT_PASSWORD` through secret-reference substitution. Never print values or write plaintext files.
